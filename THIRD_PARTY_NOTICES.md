# Third-party notices and research provenance

Original contributions and third-party material must be distinguished when reusing this academic repository. Dependency packages retain their own licenses; package-manager license metadata does not by itself license every file in this repository. No new repository-wide license is granted by this maintenance pass.

The reference example and several notebooks contain material titled **Audio Classification Beginner Tutorial**, attributed in the preserved text to **Alberto**, originally describing the Free Spoken Digit Dataset. The exact original tutorial URL and applicable license were not preserved and still need to be recovered. These portions must not be represented as wholly original work. Dataset licenses and the provenance of the adapted voice-label experiments must be documented separately.
